# Amazon Prime Video Data Analysis

## 📌 Overview
This project analyzes Amazon Prime Video's content library using data analysis and visualization techniques.

## 📊 Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📁 Dataset
- titles.csv
- credits.csv

## 🔍 Key Insights
- Movies dominate the platform
- Drama and Comedy are top genres
- Content production increased over time
- Ratings mostly fall in mid-range

## 💼 Business Impact
Helps improve content strategy, user engagement, and decision-making.
